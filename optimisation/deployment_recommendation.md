# F3 — Deployment decision framework

The 90-second target is an end-to-end budget from fault signature to local alert, not an allowance for one model invocation. The pipeline has a 30-second feature window advancing every 10 seconds. Under this design, a fault appearing just after the start of a window can wait nearly 10 seconds until the next complete inference window (or up to the windowing policy's exact worst case), leaving the remainder of the 90-second SLA for sampling, filtering, inference, logging, and alert actuation. Measure the sensor-to-alert p95 and worst observed time on the selected hardware; the supplied Roofline ideal bound of 2.81 ms is not a measured result.

The preferred hardware candidate is Raspberry Pi 5 (8 GB) plus AI HAT+ at the specified 7.5 W/₹15,000, conditional on actual sustained power, thermal, memory, and runtime measurements. Its stated 8 GB RAM provides substantial capacity for a six-feature MLP and Python/TFLite runtime, but the project's assignment does not state flash or SRAM capacity for the Pi/HAT combination. Record actual storage and peak RSS from the deployment test instead of inventing flash/SRAM values. The Hailo accelerator is only credited if the model is compiled and benchmarked in its supported toolchain; this repository's TFLite CPU path does not claim accelerator utilization.

Select among M1–M3 only from `optimisation/results/benchmark_results.csv`. The deployment candidate must satisfy both validation accuracy ≥88% and Critical recall >95%, and then be compared on latency, size, and estimated energy. If no model passes the Critical-recall gate, the defensible decision is **do not deploy to pharmaceutical cargo yet**; revise features/data/model and repeat validation. Do not select M3 merely because it is smaller, and do not claim class recall from overall accuracy. The report's final answer must name the measured eligible variant, include its actual Class 2 confusion-matrix denominator, state exact hardware/runtime, and distinguish laboratory simulation from a field pilot.
